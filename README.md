# E-commerce Database Analysis (SQL)

## Project Overview
Analyzed e-commerce sales data using MySQL to uncover business insights. This project demonstrates database design and advanced SQL querying.

## Tools Used
- MySQL (DB Fiddle)
- SQL (Joins, Aggregations, Group By)

## Key Steps
1. Database Design: Created 4 tables (customers, products, orders, order_items) with Primary Keys.
2. Data Insertion: Inserted sample data for testing.
3. Analysis: Wrote SQL queries to extract actionable insights.

## Key Insights
- Total Revenue: $3,450
- Top Customer: Ali Khan ($2,050)
- Most Profitable Category: Electronics
